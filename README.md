## Question 5. 
The Probability Density function must be normalized to the experimental values obtained in the lab. In order to properly normalize, the mean is used to center the graph, and the standard deviation sets the width of the probability density. Breaking up the histogram into a number of bins, we are able to find the edges of the graph. This allows for a normalization of the probability density to the bin widths and the number of samples.
